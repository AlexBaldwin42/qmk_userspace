Simityl gaming mode

Reference card for LAYER_GAME and LAYER_GAME_FN, from users/simian/wrappers.h. The game layers have no tap-hold keys, so a held key just stays held.

Hold the FN thumb key (or press F) to preview the FN layer.

Turning it on and off

  1. On: hold / (or Q) to open the adjust layer, then tap G.
  2. Off: tap the same / key (bottom-right corner). That position is GAME_TOG on the game layer, and it also works while FN is held.
  3. Unplugging the keyboard also leaves gaming mode. It isn't saved, so the board always boots into the normal layout.

While gaming mode is on, auto-mouse is turned off, so moving the ball never switches to the pointer layer. The mouse buttons are on the game layer itself, in the same spots as on the pointer layer.

How you know it's on

It isn't a single colour, because every hue is already close to another indicator. Instead, the whole board turns purple and only the keys that matter light up white:

  • Game layer: W A S D are lit.
  • FN held: the number keys are lit instead.

No other mode lights individual keys, so the pattern means gaming mode. The normal rainbow swirl means you're typing. Tick LED preview above to see it.

The indicator follows the brightness setting and needs RGB turned on. If the LEDs are off (RM_TOGG), gaming mode gives no visual signal.

Why the left hand is shifted one column

A 36-key board has no column to the left of A. So every left-hand key sends the letter one column to the left of its normal keycap. Your hand stays on its usual home position (index finger on F), but the game gets WASD laid out like a full-size keyboard. The free pinky column becomes plain Tab, Shift and Ctrl, which you can hold as long as you like.

The top and bottom rows shift the same way: Q W E R T sends Tab Q W E R, and Z X C V B sends Ctrl Z X C V. T, G and B no longer fit, so they're on the FN layer.
